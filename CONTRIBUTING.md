# Contributing

Thank you for your interest in CORROTECH CPQ!

At this time, this repository is maintained solely for internal purposes and **we are not accepting open-source contributions, pull requests, or feature requests**. 
Once the application has been fully completed in accordance with CORROTECH OSTRAVA’s requirements, there may be a change in approach with regard to the general CPQ application.

If you find this project useful, feel free to fork it and adapt it for your own needs (in accordance with the repository's license). However, any pull requests or issues submitted to this repository will be most likely politely closed.

Thank you for understanding!
